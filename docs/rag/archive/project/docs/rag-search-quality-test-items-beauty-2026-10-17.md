예를 들어 `블러셔 추천`, `입술 보습 립밤 추천`은 기대 상품이 상위 5개에 없었습니다. 재작성 전후로 순서가 바뀐 사례가 있어, 인덱스 재작성 뒤 순위 안정성도 따로 확인해야 합니다. 반대로 `클렌징 오일 추천`, `게임용 기계식 키보드 적축 추천`은 범위 밖인데도 무관한 뷰티 상품을 반환했습니다. 검색 연결과 근거 출처는 정상이어도 관련성 순위와 범위 차단 품질은 충분하지 않습니다.

## 별도 8개 탐색 질의

정리 전 다른 8개 자연어 질의 세트에서는 Hit@1이 5/8, Hit@5가 8/8, 평균 Precision@5가 0.35였습니다. Hit@5 8/8은 각 질의에서 적어도 하나의 임시 정답이 상위 5개 어딘가에 있었다는 뜻입니다. 1위 적중은 5/8이었고, 이 8개 결과를 이번 10개 질의 점수와 합산할 수는 없습니다. 현재 인덱스에서 저장된 상품명 그대로 검색하는 별도 쉬운 점검은 균등 간격으로 뽑은 30개 중 30개가 1위였습니다.

예전에 보신 `7/8`은 현재와 다른 데이터 및 평가 기준에서 나온 과거 수치입니다. `test_items/beauty`의 정확도로 해석할 수 없습니다.

## 평가 주소가 열리지 않았던 이유

2026-10-15 평가 manifest는 검색 API를 `127.0.0.1:8003`으로 설정했지만, 현재 검색 API는 `127.0.0.1:8002`에서 실행 중입니다. 예전 평가기는 검색 API 외에도 원본 라벨을 대조하는 API `172.30.1.53:8001`을 요구했습니다. 이 원본 API는 이번 정리에서 중지·제거했습니다.

따라서 예전 평가 명령을 설정 그대로 실행할 수 없다는 말이었고, `test_items/beauty`를 직접 검색해 평가할 수 없다는 뜻은 아니었습니다. 이번 재평가는 8002에 질의를 보내고 반환 근거 116개를 현재 DB와 직접 대조해 수행했습니다.

## 한계

10개의 긍정 질의와 2개의 범위 밖 질의는 작고, 정답 상품도 상품명 규칙으로 고른 임시 라벨입니다. 따라서 70%·80%는 공식 정확도나 사람 평가 점수가 아닙니다. 현재 결과는 상위 5개 후보 회수는 일정 수준 있지만 1위 순위와 범위 밖 질의 차단이 불안정하다는 탐색 신호입니다. 정식 품질 수치에는 사람이 승인한 질의별 관련 상품 목록, 별도 holdout 질의, 반복 측정이 필요합니다.
