# test_items2/beauty 검색 비교: BM25와 BGE-M3

작성일: 2026-10-20

상태: 탐색 평가 완료

## 요약

기존 `test_items2/beauty`의 96토큰 청크 78,595개를 다시 만들지 않고, 각 청크의 기존 `embedding_text`로 BGE-M3 1,024차원 벡터를 추가했다. 같은 긍정 질의 10개와 범위 밖(OOD) 질의 2개로 다음 검색을 비교했다.

1. BM25 단독
2. BM25 + BGE-M3 dense 하이브리드 (상품 단위 RRF, `k=60`)
3. BGE-M3 dense 단독

이 표본에서는 하이브리드가 Hit@1, Macro Recall@5, Macro MRR@5, Macro Precision@5에서 가장 높았다. 다만 정답 라벨이 규칙 생성 후 사람 검수를 거치지 않았고 긍정 질의도 10개뿐이므로, 운영 정확도나 일반적인 모델 우열로 해석하면 안 된다. 세 구성 모두 OOD 질의 2개에 결과를 반환했다. 검색 결과를 거절하는 임계값은 이번에 평가하지 않았다.

## 질의 및 검색 시간

단위는 밀리초이며, 12개 질의를 한 번씩 실행한 결과다. 검색 시간은 BGE-M3 질의 임베딩 시간을 제외한다.

| 측정값 | BM25 단독 | BM25 + BGE-M3 | BGE-M3 dense 단독 |
| --- | ---: | ---: | ---: |
| 질의 임베딩 p50 / p95 | — | 70.544 / 122.615 | 71.472 / 102.733 |
| 검색 p50 / p95 | 54.520 / 67.430 | 81.858 / 3,266.474 | 702.144 / 772.439 |

표본이 12개라 p95는 한두 번의 긴 요청에 크게 좌우된다. 하이브리드 검색 p95가 3.27초로 측정됐으므로, 이 값은 재측정과 지연 구간 분석 없이 운영 성능으로 일반화하지 않는다. 부하 테스트나 반복·워밍업을 포함한 SLA 측정은 이번 범위에 없다.

## 평가 중 발견한 BM25 실행 오류

평가 중 반복 검색에서 ParadeDB가 `Unsupported query shape` 오류를 반환했다. DB `5432/toss_rag`에서 같은 BM25 SQL을 기본 Psycopg 자동 준비 설정으로 40회 실행했을 때 3회 실패했고, 해당 실행에 `prepare=False`를 지정한 경우 40회 모두 성공했다. 이에 BM25 쿼리만 자동 준비에서 제외하고 회귀 테스트를 추가했다. 수정 뒤 고정 질의 12개를 3회 반복한 36회 검색과 전체 평가가 완료됐다.

## 해석과 한계

- 이 고정 질의 집합에서 하이브리드는 BM25 단독보다 Hit@1이 20%p 높고 Macro Recall@5가 0.0661 높았다. 10개 질의 중 2개가 Hit@1 결과를 바꿀 수 있는 작은 표본이다.
- Dense 단독은 Hit@1에서 하이브리드와 같았지만 Hit@5와 Macro Recall@5는 더 낮았다. 따라서 현재 결과만으로 BM25를 제거하는 결정을 내리지 않는다.
- 기대 상품 라벨은 상품 유형·제목 규칙으로 만들었으며 사람이 검수하지 않았다. 관련성 판정이 불완전하거나 질의 의도를 충분히 대표하지 않을 수 있다.
- 긍정 질의는 10개, OOD 질의는 2개다. 이는 일반 정확도, 카테고리 전반 성능, 운영 검색 품질의 추정치가 아니다.
- 두 OOD 질의에서 모두 결과를 반환했지만, 이 실험은 무응답 임계값이나 안전한 거절 정책을 평가하지 않았다.
- 답변 생성기, 리랭커, BGE-M3 sparse/ColBERT 검색은 비교하지 않았다.
- BGE-M3는 별도 임베딩 컴포넌트로 추가했으며, 이번 측정만으로 서비스 검색 설정을 전환하지 않았다.
