# RAG 검색의 현재 방향

현재 검색 범위는 `test_items` 데이터의 `beauty` 범주입니다. RAG API는 상품 후보와 원문 근거를 찾고, 최종 추천이나 정책 판단은 별도 계층이 맡습니다.

## 색인 흐름

상품과 리뷰를 색인 전에 작은 근거 청크로 나누고, 청크 원문·출처 위치·임베딩을 PostgreSQL에 저장합니다. 상품과 리뷰는 `product_id`로 연결하며, 한 데이터 버전의 색인을 완성한 뒤 활성 색인을 교체합니다.

## 검색 흐름

1. 요청의 질의문을 벡터로 변환합니다.
2. pg_search의 BM25와 pgvector 검색으로 각각 후보 청크를 찾습니다.
3. Reciprocal Rank Fusion으로 상품 순위를 결합합니다.
4. 상품별 근거 청크와 원문 출처를 반환합니다.

검색 응답은 정답 확률이 아닙니다. 순위 품질은 사람이 승인한 질의·정답 목록과 분리된 holdout 세트로 평가해야 합니다. 현재 `test_items/beauty`의 직접 점검 결과와 한계는 [검색 품질 보고서](../../docs/rag-search-quality-test-items-beauty-2026-10-17.md)에 기록했습니다.
