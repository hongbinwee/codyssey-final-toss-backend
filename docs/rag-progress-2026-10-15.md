- Tuning: RAG-003/004 통과. RAG-001은 대상 상품은 찾았지만 기대 리뷰 출처가 상위 결과에 없습니다. RAG-002는 상품을 찾았으나 라벨에 지정된 정확한 출처 범위가 없습니다.
- Holdout: RAG-007/008 통과. RAG-005는 기대 상품 미적중, RAG-006은 기대 상품은 찾았지만 정확한 기대 출처가 없습니다.

- holdout은 잠정 결과입니다. 팀 라벨 승인이 없고, 앞선 탐색 holdout 이후 API ranking-contract 일관성 수정이 들어가 독립성이 인증되지 않았습니다. holdout 결과를 근거로 관련성 파라미터를 튜닝하지 않았습니다.
- `RAG_MIN_RRF_SCORE`는 미설정 상태로 유지했습니다.

Holdout RAG-008 첫 요청은 `database_failed`를 반환했고, API 로그에는 `InternalError_`, SQLSTATE `XX000`만 안전하게 기록됐습니다. 한 번 재시도한 검색은 성공했습니다. 원인은 특정하지 못했으며 운영 DB 오류가 해결됐다고 간주하지 않습니다.
